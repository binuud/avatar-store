# avatar-store

A store for all Avatar Agents, this will act like a server for agents

* avatarStore - list of Avatar md files
* * avatar-name - folder
* * * avatar-name.md markdown file containing instructions and front matter for avatar
* * * avatar-name-ui.yaml ui components array in yaml format, can be generated using ai
* * * avatar-name.png 400 x 400 image for store front

The Avatar Agent md files have to be built, before using them.
